# Rudi Willock

Backline systems tech and builder based in Indianapolis. I run Filament Audio, where I repair tube amps, synths, and pro audio gear.

I build things, fix things, and document the process. Repair videos, custom electronics, circuit design through final assembly. I also write and produce music, collect records, and generally believe there's art in everything if you look close enough. A power supply schematic, a worn tine on a Rhodes, a dusty 45 from a thrift store crate. It's all the same thing to me.

**What lives here:** the source for [rudimakes.com](https://www.rudimakes.com), my repair log, build projects, and whatever else I'm working on.
